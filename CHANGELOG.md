# Changelog

Заметные изменения ReMind с момента добавления Telegram-интеграции. Изменения сгруппированы по дате и назначению; внутренние мелкие правки и отдельные обновления зависимостей объединены.

## 2026-09-28

- Разделены крупные модули чата, поиска, GitHub и Telegram на компоненты с более ясными зонами ответственности; сохранены прежние точки входа.
- Упорядочены базовые CSS-токены и удалены повторяющиеся объявления стилей.
- Обновлены Python- и Node.js-образы, интегрированы обновления зависимостей и удалена конфигурация Dependabot.

## 2026-09-27

- Добавлен сценарий исследования с защищёнными инструментами чата и возможностью запускать последовательные действия.
- Веб-запросы направляются через специализированные промпты; для новостей предусмотрен поиск по вебу, если новостная лента пуста.
- Переработаны панели рассуждений и вызовов инструментов; восстановлен индикатор уровня рассуждения и скрыты пустые сведения о контексте.
- Добавлены всплывающая панель использования контекста сессии и скачивание файлов, созданных в чате.

## 2026-09-13

- Переписка гостя переносится в аккаунт после входа, чтобы продолжать разговор без потери контекста.

## 2026-09-12

- Обновлены стили и удалены устаревшие файлы интерфейса.

## 2026-09-11

- В настройках появился системный шрифт; улучшена доступность элементов интерфейса.

## 2026-08-31

- Добавлено восстановление пароля с проверкой запросов и защитой от перебора.
- Добавлены инструменты работы с изображениями и их анализа.

## 2026-08-15

- Улучшено автозаполнение полей входа и регистрации в Safari и других браузерах.
- Исправлено поведение автозаполненного пароля при переключении его видимости.

## 2026-08-11 — 2026-08-13

- Добавлен изолированный запуск Python-кода, в том числе для визуализаций и результатов в Canvas.
- Результаты Python с изображениями отображаются прямо в Canvas; улучшено отображение номеров строк и консоли.
- Обновлены промпты и общий API вызова инструментов.
- Добавлена авторизация Apple. Устаревший iOS-проект удалён из основного репозитория.
- Обновлена базовая версия Python-контейнера.

## 2026-08-07 — Telegram

- Добавлен Telegram-бот и возможность связывать его с аккаунтом ReMind.
- Добавлены обработчики команд и callback-кнопок, загрузка фотографий и ответы для гостевых пользователей.
- Улучшено восстановление контекста при повторной генерации ответов.
