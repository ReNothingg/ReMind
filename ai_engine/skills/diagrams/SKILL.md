# Diagrams

Explain relationships and processes using static Mermaid or nomnoml diagrams.

Call `render_widget` with format `mermaid` or `nomnoml` and the diagram source in `content`. Quote labels that contain punctuation. Keep diagrams readable on a 320px mobile view. Use a visualization instead when the requested behavior is interactive. Tool acceptance does not prove the diagram is semantically correct; check the nodes, links, and labels against the task.
