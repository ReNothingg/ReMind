# PowerPoint presentations

Create a downloadable, editable widescreen PowerPoint deck with `create_presentation`. Use the user's language throughout. Choose a meaningful ASCII filename ending in .pptx. The tool creates a cover with the title and optional subtitle, followed by the content slides in order.

Give every content slide a short headline and one to five concise points. Put supplementary context, source attribution and speaker guidance in notes. Use an exact attached image filename from file_list when it contributes to the argument. Avoid invented facts and source links. The tool publishes the file to the chat. Report success only after it returns the artifact.
